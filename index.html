Introduction

For our Assignment 1 project, we aimed to use the dataset “Daily Weather in the U.S., 2017” from NOAA to represent each state/province in mainland North America and depict both its relevant temperature statistics as well as its precipitation statistics over time. The specific temperature variables involved were Average Minimum Temperature, Average Maximum Temperature, and Average Daily Temperature. and the specific precipitation was Monthly Precipitation and Monthly Snow. The user is able to toggle between each of these variables via two dropdowns, with the visualization representing one temperature statistic and one precipitation statistic at a time. Additionally, a slider shows what month in 2017 the statistics are from, with the user being able to use the slider to change the month and watch the data change over time.

Visual Description

The visualization of this data is projected onto a map of mainland North America, with localized circles representing 49 mainland US States (Hawaii omitted as it is not mainland) and 9 Canadian provinces (Saskatchewan was absent from the dataset, so it was omitted) alongside Northern Territories. Each circle is sized based on the precipitation variable, with a larger circle representing higher precipitation amounts. Additionally, the circles are colored based on the temperature variable, with red representing warmer temperatures while blue represents cooler temperatures. Below the visualization is a key which depicts a gradient from blue to red, where both sides of the color spectrum are labeled to their corresponding temperature. In addition to this, a small, medium, and large circle depicted with its corresponding precipitation measurement are shown to help the user interpret the circle sizes on the map. The default units in the visualization are metric, but can be changed to US Customary via a dropdown at the top of the page. The final feature of the visualization are the tooltips, which show when mousing over a circle. The tooltip shows the shortform name of the state/province/territory (i.e. MD for Maryland) alongside the specific values of the currently visualized statistics with a label. The values shown will change based on which statistics the user has chosen to be visualized.

Assignment criteria (Interactions, rationalle and encodings)

Dynamic filters or queries from Category 1 and Details-on-demand from Category 2 were implemented in this project. The series of dropdowns to change to specific temperature and precipitation statistics filter the data to exactly what information the user wants to see, and the month slider filters the data to when the user wants to see it from. The reasoning behind this is so that the user can easily see all of the data without overplotting the details. The user is able to query the information they want and see how it plots on the map. Details-on-demand was implemented via the tooltip feature, where the specific values that are being visualized can be read directly if the user hovers over the corresponding circle. The reason this was kept as a tooltip and not directly shown is to emphasize the trends on the visualization while still allowing the user to find out the specific values that are being represented.

Overall, this visualization will show the user more than just the data. For example, if the user focuses on the color of the circles on the map, they may find that the northern locations are generally cooler than the southern locations on the map. Additionally, they may notice a gradient of precipitation amounts, with coastlines having significantly more precipitation than landlocked regions, or that the northeast of the United States is a hotspot for snow in January but not rain. The dynamic features of the map are what allow the user to notice location trends throughout the various months.

To recap the main encodings that exist: Time encodes to label over a slider input, location encodes to the position of a corresponding circle on a map of mainland North America and can be identified by a tooltip, temperature encodes to the color of the circle, and precipitation amount encodes to the radius of the circle. Time being on a slider aims to represent a timeline, with the ordinal data of months being listed in order along the slider, allowing the user to traverse the data both forwards or backwards in time in 2017. The nominal location data encodes to position on a map to allow the user to easily find the data of a location using their preexisting knowledge of a map but also to represent regional trends. To elaborate on this, a bar graph of each state with its corresponding temperature would not allow the user to see that a certain region on a map shares a common trend. By putting locations on a map, the user is able to see these location-based trends and draw conclusions from the data without explicitly being told the trend exists. The continuous, interval data temperature encodes to a sequential, fixed-range color scale, with the scale being blue which progressively gets more red as the temperature increases. The rationale for this stems from how blue is generally associated with cold, and red with hot. While we did consider a diverging color scale, the color scale is sequential since the 0 in the scale does not lie in the middle, let alone that it is inconsistent between fahrenheit and celsius, meaning that a diverging scale would not be useful since the spectrum lacks a meaningful midpoint. We also considered a dynamic range for the color scale, but settled on a fixed range. The range is fixed between the average max, min, and daily temperature statistics in order to visually show the difference between each of the statistics when toggled between. A dynamic range would end up with each location having a relatively similar color despite holding different values for average min and max temperatures, which would prevent the user from identifying certain trends in the data. Precipitation amount encodes to size because precipitation is quantitative, so size can effectively visually demonstrate whether an area has more or less precipitation by having either a bigger or smaller circle. The data is both accurately and effectively represented this way.
